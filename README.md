# macro-symbiosis.net

The published files of [macro-symbiosis.net](https://macro-symbiosis.net): a research framework under open development. This repository is generated automatically; please do not open pull requests here.

* `source/`: the published texts (spine, corpus, site pages) as Markdown, with the spine's equations (`r7`, JSON) and verification script.
* `html/`: the built website, served as is.

What is and is not claimed is set out on the site's home page. In short: the spine's internal consistency is checked to the extent of its recorded witnesses; every mapping and prediction is a hypothesis, and none has been tested yet; nothing is claimed about consciousness.
